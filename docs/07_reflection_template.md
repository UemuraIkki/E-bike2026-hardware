# 7. 感想テンプレート

このファイルへ個人の感想や実名を書かない。各自がローカルへコピーし、GitHub外で記入する。

## 記入項目

1. 自分の担当
2. 最初に立てた目標
3. 実際に行った作業
4. 最も難しかった問題
5. 問題の原因をどう切り分けたか
6. 失敗した方法と、そこから分かったこと
7. 他担当との連携で学んだこと
8. 次に改善するとすれば何をするか
9. 工学的に身についた知識・技能

## 書き出し例

> 私は主に［担当内容］を担当した。開発前は［当初の予想］と考えていたが、実際には［発生した問題］が起こった。そこで［測定・比較・改修］を行い、［得られた結果］を確認した。この経験から、［学んだこと］が重要だと分かった。

感想は「大変だった」「楽しかった」だけで終わらせず、具体的な作業、判断、測定結果と結び付ける。
