# 5. 装置・ソフトウェアの動作試験

## 5.1 試験記録の原則

試験結果だけでなく、再現できる条件を残す。最低限、次を記録する。

- 試験日、匿名担当、目的
- 使用したWorkbench設定またはコミット
- 電源電圧、電流制限、負荷条件
- モータ指令値、回転数、電流、温度
- 測定器と測定位置
- 期待結果、実測結果、合否
- 発生したFaultと復帰方法
- 写真・波形・ログのファイル名

テンプレートは [evidence/test-log-template.md](evidence/test-log-template.md) を使用する。

## 5.3 今後必要な試験

### モータ単体

1. 速度制御800、1200、1500rpmで各1分運転する。
2. 電源電流、Motor PilotのIq、回転方向、Faultを記録する。
3. トルクモードへ移行し、指令を1000 s16A程度から段階的に上げる。
4. 3500rpmで速度キャップが作動することを確認する。
5. キャップ解除時にチャタリングや急加速がないことを確認する。

### Hallセンサ

1. H1/H2/H3をオシロスコープで同時測定する。
2. 6状態が正しい順序で遷移することを確認する。
3. 正転・逆転で遷移順を記録する。
4. 300°設定で速度表示と実回転が一致するか確認する。

### CAN通信

1. CAN_H/CAN_Lの差動波形と終端抵抗を確認する。
2. 無荷重時の受信フレームを1000件記録する。
3. 既知荷重を段階的に加え、センサ値との対応を測定する。
4. 配線外れ、センサ停止、タイムアウト時の挙動を確認する。

### 車体・機械

1. ブレーキ修理後の左右制動と引きずりを確認する。
2. ワッシャの寸法、緩み、偏心を確認する。
3. ペダルを連続回転させ、配線に引張りやねじれが生じないか確認する。

### 統合・耐久

1. 後輪を浮かせた状態でアシスト開始・停止を確認する。
2. 人力入力0でモータ指令0となることを確認する。
3. アシストが人力の2倍を超えないことを確認する。
4. 車速24km/h相当以上でアシスト0となることを確認する。
5. 約2時間運転し、バッテリー電圧、電流、モータ・インバータ温度を記録する。

公道での試験は、車体、安全装置、法規適合を確認するまで実施しない。
