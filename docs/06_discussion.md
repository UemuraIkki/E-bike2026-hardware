# 6. 考察

## 6.1 実現できたこと

- STM32L476RGと3相インバータを用いたBLDCモータ制御環境を構築した。
- MCSDKのセンサレスFOCでモータを回転させた。
- 速度制御、トルク制御、Fault処理の実装箇所を確認した。
- Hall信号、回路、電気角を検証し、オフセット300°を測定した。
- CAN通信モジュールの設計・製作・検証を進めた。
- 車体のブレーキ修理とトルクセンサ取付部品の製作を行った。
- ペダル回転でトルクセンサ配線が引っ張られる問題を解決した。

## 6.2 実現できていないこと

- 人力トルクに応じた連続的なアシスト制御の完成。
- モータトルクがセンサへ回り込む影響の分離。
- Hall方式の安定運用。
- 24km/h停止と人力2倍上限を含む車体上での定量試験。
- 約30km、約2時間の走行に必要なバッテリー容量の実証。

## 6.3 センサレスFOCの問題

センサレスFOCは逆起電力から回転子位置を推定するため、停止・低速・急激な負荷変化に弱い。E-bikeでは発進や坂道で低速高トルクが必要であり、この弱点が大きい。

負荷を加えた際の逆回転は、実回転子角度と推定角度の同期が外れたままq軸電流を与えた可能性が高い。信頼性低下、逆回転、過速度を検出してIqを0にする対策は被害を抑えられるが、位置推定そのものを回復させるものではない。

対策候補は次の通りである。

- センサレスFOCを維持し、最低速度・信頼性・方向を監視する。
- Hall回路と信号品質を改善し、低速域をHallで制御する。
- Hallと観測器を速度域で切り替えるハイブリッド方式を検討する。

現状はセンサレス方式で段階試験を進めるが、停止からの強いアシストを要求する場合は位置センサ方式を再検討する必要がある。

## 6.4 人力トルク分離

トルクセンサがペダル軸にあり、モータトルクが同じ軸へ戻る構成では、センサ値が人力とモータ力の合計になる可能性がある。単純にセンサ値へ比例したモータ出力を与えると、正帰還となる危険がある。

候補は次の3方式である。

1. センサより下流へモータを接続し、後輪などを直接駆動して機械的に人力だけを測定する。
2. クランクまたは伝達部へラチェット、フリーホイール、一方向クラッチを設け、モータトルクの逆流を防ぐ。
3. センサ値から `Kt × モータ電流 × 伝達比` を差し引くモデルベース推定を行う。

機械的分離が最も確実である。モデルベース方式は改造量を抑えられるが、摩擦、チェーン張力、遅延、温度変化を校正する必要がある。

## 6.5 トルクセンサ配線

開発初期には、ペダル回転に伴ってトルクセンサ配線が引っ張られ、断線する問題があった。この配線問題は現在までに解決している。

ただし、採用した固定方法の構造、使用部品、作業時期、連続回転時の確認条件は資料に残っていない。最終レポートでは、解決前後の写真と固定方法を示し、ペダルを連続回転させても配線へ引張りやねじれが生じないことを確認結果として記載する。

## 6.6 バッテリー容量

7Aで2時間使用すると単純計算で14Ahとなり、既存10Ahでは余裕がない。ただし実際のアシストは常時7Aではないため、必要容量は平均電流の実測で決めるべきである。電圧降下、BMS遮断、温度、劣化余裕を考えると15〜20Ahも候補となる。

2026年4月時点では、充電後の既存バッテリー端子電圧が18.9Vであったとの記録から、劣化またはBMS異常が疑われた。しかし、充電器出力、各セル電圧、BMS遮断状態を測定していないため、BMS故障と断定はできない。交換判断の前に、端子電圧だけでなくセルバランスと負荷時電圧降下を確認する必要がある。

## 6.7 設計レビューから得た論点

中間発表と発表準備では、次の設計上の質問が挙がった。これらは単なる質疑対策ではなく、完成判定と第5章の試験項目へ反映する必要がある。

- 車速計算をタイヤ径と磁石数の違いへどう対応させるか。
- モータ指令0のとき、駆動系が空転できるか、不要な走行抵抗を生じないか。
- 現在のチェーン駆動と、前輪またはインホイールを直接駆動する方式を、安全性、加工量、人力分離の観点で比較したか。
- 片側だけでなく左右のペダル入力を評価できるか。
- 磁気センサが検出する量と、人が加えた力との対応を説明できるか。
- 回路の小型化について、体積・質量・取付面積などの目標値を定めているか。
- 過電流、過熱、短絡、バッテリー異常、磁石脱落、信号線断線に対する安全状態を定義しているか。
- Fault後の自動再起動が、意図しない急発進につながらないか。
- 市販の電動アシスト自転車に対する、試作システムの教育的・技術的意義を説明できるか。
- 屋外、坂道、連続運転を含む実車試験をどの条件で行うか。

特に車輪磁石方式は、タイヤ外周 `C` [m]、1回転当たりの磁石通過数 `N`、パルス周期 `T` [s] を用いて `v = C / (N × T)` [m/s] と計算できる。タイヤを交換した場合は `C` を再設定し、磁石数を変更した場合は `N` を再設定する必要がある。実車では公称タイヤ径だけでなく、実測した転がり外周を使う方が誤差を抑えられる。

## 6.8 今後の優先順位

1. CANフレーム仕様とトルクセンサ校正を確定する。
2. トルクセンサ固定と人力分離方式を機械図で確定する。
3. 3500rpm速度キャップを含むモータ単体試験を完了する。
4. 人力2倍上限と24km/h停止をコード・実測の両方で確認する。
5. 連続運転で温度と消費電力量を測定し、バッテリーを選定する。
