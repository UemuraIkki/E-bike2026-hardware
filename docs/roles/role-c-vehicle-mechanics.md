# 担当C: 車体整備・機械加工

制御が正しくても、止まれない自転車は走らせられない。開発初期には、ペダルを回すたびにトルクセンサ配線が引っ張られる問題もあった。担当Cは、電子回路の外側にあるこれらの問題を受け持った。

## 行った作業

車体側では、実走へ向けた整備としてブレーキの修理と調整を行った。モータやセンサの試験を車体上で行うには、左右の制動、引きずり、部品の緩みを先に確認する必要がある。

トルクセンサはペダル軸へ仮取り付けされていたが、そのままでは位置が安定しなかった。そこで、取付位置を調整するためのワッシャを設計・製作した。機械部品は形が合うだけでは足りない。外径、内径、厚さ、材質、公差がずれると、偏心や緩みが生じ、センサ値や安全性へ影響する。

もう一つの課題が配線であった。ペダルとともに回転する部分から固定側へ線を出すと、配線には引張りとねじれが加わる。固定方法を改良し、この配線問題は解決した。ただし、採用した構造と作業時期は現在の資料に残っていない。

## 作業の要点

- 自転車の状態確認
- ブレーキの修理・調整
- 修理後の制動と引きずりの確認
- トルクセンサ取付用ワッシャの設計・製作
- ワッシャとセンサの組付け
- 配線の引張り・ねじれ・断線問題の確認と解決
- 緩み、偏心、部品干渉を防ぐ固定方法の改良

## 到達点と残った課題

車体整備と取付用ワッシャの製作を進め、トルクセンサを車体へ固定するための形は作った。しかし、修理前後の写真、ワッシャ寸法、材質、加工方法、制動試験の数値が十分に残っていない。

配線の問題は解決済みである。今後必要なのは、解決方法を再検討することではなく、固定構造の写真、使用部品、ペダル連続回転時の確認条件と結果を記録することである。

車体は制御プログラムの入れ物ではない。ブレーキが効き、部品が外れず、配線が切れないことまで確認して、初めてモータ試験を実車へ移せる。
