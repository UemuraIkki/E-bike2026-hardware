# 2. 装置・ソフトウェアの仕様

このファイルをレポート用数値の基準とする。過去のWorkbench設定やコード中に異なる値がある場合、実験値として区別し、ここへ無断で反映しない。

## 2.1 ハードウェア

| 項目 | 仕様 |
|---|---|
| 制御ボード | NUCLEO-L476RG |
| MCU | STM32L476RG、bxCAN内蔵 |
| パワーボード | X-NUCLEO-IHM08M1、3相インバータ、最大出力電流10A |
| モータ | ZGC 57DMWH75-2440、24V BLDC |
| モータ極対数 | 2 |
| 定格回転数 | 4000rpm |
| 無負荷回転数 | 5000rpm |
| 定格トルク | 0.28N·m |
| 定格電流 | 7A |
| 駆動伝達 | チェーン駆動 |
| トルクセンサ | BF SR系、CAN出力、詳細型番は要確認 |
| CANトランシーバ | SN65HVD230、VCC=3.3V |
| Hallセンサ | 3個、Hall Profiling実測オフセット300° |
| バッテリー | 24V、既存10Ah、容量再検討中 |

MCP2551は5Vロジックのため、STM32の3.3Vロジックへ直接使用しない。SN65HVD230はSOIC-8でMCP2551とピン互換だが、VCCを3.3Vとする。

## 2.2 ソフトウェア

| 項目 | 仕様 |
|---|---|
| IDE | STM32CubeIDE |
| モータ制御SDK | X-CUBE-MCSDK 6.4.2 |
| 調整ツール | Motor Control Workbench、Motor Profiler、Motor Pilot |
| 現行制御方式 | センサレスFOC、State Observer + PLL |
| Motor Pilot接続 | ST-Link Virtual COM Port、1843200baud |
| デバッグ方式 | SWD |

JTAGを使用するとPA15（JTDI）とPB3（JTDO）がHall入力TIM2_CH1/CH2と競合するため、SWDへ固定する。

## 2.3 電流・トルク換算

| 項目 | 値 |
|---|---|
| 可測電流範囲 | ±30.69A |
| 電流換算 | 約1068 s16A/A |
| 7A相当 | 約7470 s16A |
| `IQ_MAX_S16A` | 6000、約5.6A |
| 初期トルク試験値 | 1000〜2500 s16A程度から開始 |
| トルク定数 | 約0.04N·m/A |
| 制御条件 | 表面磁石相当、`id=0`、MTPA不要 |

定格トルクと定格電流から、`Kt = 0.28 / 7 ≈ 0.04N·m/A` とする。

## 2.4 既知の実測値

| 項目 | 結果 |
|---|---|
| 無負荷ドラグ電流 | 低速で約0.5A |
| 5000rpm付近の無負荷電流 | 約1.2A |
| Hall電気角オフセット | 300° |
| ベンチ電源電流制限 | 3A未満ではUnder Voltage Faultが発生したため3A以上 |

## 2.5 センサレスFOCの制約

- 停止・低速では逆起電力が小さく、観測器が回転子位置を推定できない。
- 0rpmでのトルク保持はできない。
- 小さすぎるトルク指令では観測器の最低速度を下回り、Speed Feedback Faultとなる可能性がある。
- トルクモードでは無負荷時に5000rpm付近まで加速し得るため、自前の速度キャップが必要である。
- 起動時は強制転流で観測器がロックする速度まで上げ、RUN到達後にトルクモードへ切り替える。

速度キャップの設計目安は3500rpmとする。過去コードの4000rpmは実験値であり、現行基準ではない。

## 2.6 法規に関する設計制約

- アシスト力は人力の最大2倍までとする。
- 車速24km/h以上ではアシストを完全に停止する。

最終的な公道走行可否は、車速換算、アシスト比、制動装置、車体全体を含めて別途確認する。

## 2.7 要確定値

- トルクセンサの完全な型番
- CANビットレート、CAN ID、バイト配置、符号、スケール
- タイヤ径、チェーン減速比、モータrpmから車速への換算係数
- トルクセンサのゼロ点、温度ドリフト、校正係数
- 連続走行時の平均電流と最終バッテリー容量
