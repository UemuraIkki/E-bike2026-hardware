# 3. 開発計画・役割分担

## 3.1 匿名での役割分担

| 匿名担当 | 主担当 | 具体的作業 |
|---|---|---|
| 担当A | モータ制御・プロジェクト管理 | MCSDK設定、速度制御、トルク制御、故障解析、安全制限、進捗管理、Hall担当とCAN担当の補助 |
| 担当B | Hallセンサ | Hall信号検証、磁石の選定・発注、Hall回路製作、Hall用プログラム作成、電気角測定 |
| 担当C | 車体・機械 | ブレーキ修理などの車体整備、トルクセンサ取付用ワッシャの設計・製作、機械固定の検討 |
| 担当D | CAN通信 | CAN通信モジュールの回路設計、製作、配線、通信試験、受信仕様の調査 |

担当Aはモータ全般を主担当とし、HallセンサとCAN通信の両方を補助する。レポートでは、各自が自分の匿名担当の節を詳しく記述する。

## 3.2 開発の段階

| 段階 | 内容 | 完了条件 |
|---|---|---|
| P1 | 車体・既存部品の確認 | 制動、駆動、取付箇所の問題を一覧化 |
| P2 | モータ速度制御 | センサレスFOCで低速から安定回転 |
| P3 | 電流換算確認 | Motor Pilot値と実電流の対応を確認 |
| P4 | トルク制御 | RUN後にトルクモードへ移行し、速度キャップが動作 |
| P5 | Hall検証 | 3信号、回路、電気角、低速安定性を評価 |
| P6 | CAN受信 | トルクセンサの生データを継続受信 |
| P7 | 人力トルク分離 | モータ駆動中でも人力成分を推定 |
| P8 | アシスト演算 | 人力に応じて出力し、2倍上限と24km/h停止を確認 |
| P9 | 車体統合試験 | 制動、配線、温度、電圧、連続走行を確認 |

## 3.3 レポート完成へ向けた作業

| 期限目安 | 作業 |
|---|---|
| 8月前半 | 既存資料の匿名整理、回路図・加工図・試験記録の回収 |
| 8月中旬 | 各担当が第4章と第5章の根拠資料を追加 |
| 8月下旬前半 | 共通仕様、考察、図表番号を統一 |
| 提出前 | 各自がローカルで実名、表紙、感想を追加しPDF化 |

正確な作業日と担当時間は、各担当の実験ノートから追記する。
