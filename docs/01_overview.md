# 1. 装置・ソフトウェアの概要

## 1.1 開発の背景

本プロジェクトでは、既存の自転車へ電動アシスト機能を追加し、人の踏力に応じてモータ出力を変化させるE-bikeを開発する。単にモータで自走させるのではなく、運転者がペダルへ加えた力を検出し、その力に対応した補助トルクを発生させることが今年度の中心目標である。

想定用途は観光地を巡る約30km、約2時間の走行である。坂道や長距離走行の負担を軽減しつつ、一般的な自転車として扱える構成を目指す。

## 1.2 実現しようとすること

システムは次の処理を行う。

1. ペダル軸のトルクセンサからCANで測定値を受信する。
2. 人が加えたトルクと、駆動系から回り込むモータトルクを可能な範囲で分離する。
3. 人力、車速、安全上限からアシスト量を計算する。
4. STM32上のFOC制御へq軸電流指令を与え、BLDCモータを駆動する。
5. 異常、過速度、法規上限を検出した場合はアシストを停止または制限する。

## 1.3 全体構成

```text
[ペダル入力]
     │
     ▼
[BF SR系トルクセンサ]
     │ CAN
     ▼
[SN65HVD230] ── [STM32L476RG]
                      │
                      ├─ 人力トルク推定
                      ├─ アシスト演算
                      ├─ 速度・電流・法規制限
                      ▼
             [センサレスFOC制御]
                      │
                      ▼
             [X-NUCLEO-IHM08M1]
                      │ 三相
                      ▼
             [24V BLDCモータ]
                      │ チェーン
                      ▼
                  [自転車]
```

## 1.4 現在の到達点

- MCSDKによるセンサレスFOCでモータを回転できる構成を作成した。
- 速度制御からトルク制御へ切り替えるコードと、トルクモードの速度監視を検討・実装した。
- Hallセンサの信号、電気角、回路、プログラムを検証したが、現状はHall方式を安定運用できていない。
- CAN通信モジュールの設計、製作、検証を進めている。
- 車体のブレーキ修理など、実走へ向けた整備を進めた。
- トルクセンサを取り付けるための機械部品を製作した。

## 1.5 未解決の中心課題

- トルクセンサ配線がペダル回転で引っ張られない固定方法。
- センサ値から「人の力だけ」を取り出す方法。
- CANビットレート、ID、データ形式を確定した受信実装。
- トルク制御の実機チューニングと安全な速度制限。
- 10Ahバッテリーで約2時間走行できるかの実測。
