# 担当B: 車速検出用Hallセンサ

磁石を検出できても、それだけでは車速にならない。必要なのは、磁石が通過した回数と間隔を測り、タイヤ外周と磁石数を使って移動速度へ変換することである。担当Bは、この車輪側の検出系を受け持った。

モータ内部の3個のHallセンサは担当Aの範囲であり、担当Bが扱ったのは車輪の回転を測るHallセンサである。二つは目的も入力方法も異なる。

## 行った作業

4月下旬から5月にかけて、車速検出に使うHallセンサと磁石を調査し、磁石の選定・発注、回路製作、取付方法の検討を進めた。

5月19日の試作では、NUCLEO-L476RGの12bit ADCでHall出力を読み取った。ADC値が320を超えた瞬間に磁石の通過を1回だけ数え、120未満へ戻るまで次の計数を待つ。二つの閾値を使うことで、境界付近のノイズによる多重計数を抑える構成とした。

通過時刻は`HAL_GetTick()`で記録し、前回との差から1回転相当の時間を求めた。計数値と周期はUARTへ出力し、ループ周期は10msとした。5月26日には、CubeMXでのADC・UART設定とコードの配置方法を班内で整理した。この部分は担当Aも補助している。

検出処理は形になったが、速度計算にはまだ値が足りない。タイヤ外周を`C` [m]、1回転当たりの磁石数を`N`、パルス周期を`T` [s]とすると、車速は`v = C / (N × T)` [m/s]で求められる。タイヤや磁石数が変われば、換算値も設定し直さなければならない。

## 作業の要点

- 車速Hallセンサと磁石の調査・選定
- 磁石の発注と取付方法の検討
- Hall回路の製作
- STM32用の計数・周期測定プログラム作成
- ADCの上側320・下側120によるヒステリシス判定
- UARTによる回数・周期表示
- タイヤ外周、磁石数、周期を使った車速計算の検討

## 到達点と残った課題

磁石の通過を数え、通過間隔を表示する単体試験コードまで作成した。ただし、センサ型番、磁石なし・ありの実測値、タイヤ外周、磁石数、実車での速度誤差は記録が不足している。

試作コードはADC1を使用している。MCSDKではADC1をモータ電流帰還に使うため、そのまま統合すると制御を壊す。実車へ組み込む際は、競合しないGPIOまたはADC入力を選び直す必要がある。

磁石を数える処理はできた。残っているのは、その数値が実際の車速と一致することを示す試験である。
